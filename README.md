# Fullstack Facebook Clone

This is a Fullstack project that aims to clone the Facebook social network as closely as possible using Spring Boot for the backend and Angular for the frontend.

## Introduction
FacebookClone is a fullstack application that mimics the functionalities of Facebook. It is built using Spring Boot for the backend and Angular for the frontend.

## Features
- User Authentication (Login/Register)
- Profile Management
- Posting Status Updates
- Commenting on Posts
- Liking Posts and Comments
- Friend Requests and Friend List Management
- Real-time Notifications
- Messaging between Users
- News Feed displaying posts from friends
- Search for users and posts

## Technologies Used
- **Backend**: Spring Boot
- **Frontend**: Angular
- **Languages**: 
  - Java (51.1%)
  - TypeScript (31.1%)
  - HTML (17.2%)
  - Other (0.6%)
